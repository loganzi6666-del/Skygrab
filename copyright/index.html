著作権・DMCA ポリシー

当サイト（Bluesky Video Downloader）は、著作権をはじめとする知的財産権を尊重します。本ページは、当サービスの技術的な位置づけと、権利者の皆さまからのご連絡への対応方針を定めるものです。

1. 当サービスはコンテンツをホスティングしていません

当サービスは、動画ファイルや画像ファイルを一切保存しません。当サービスが行うのは、利用者が入力した Bluesky の公開投稿 URL について、AT Protocol の公開 API に問い合わせ、そのメディアの所在（Bluesky が運営する公開 CDN 上の URL）を特定し、利用者のブラウザに返すことのみです。

ファイルの転送は、利用者のブラウザと Bluesky の配信サーバーとの間で直接行われます。当サイトのサーバーを経由することはなく、当サイト上でコンテンツを一覧化・再公開することもありません。

2. 技術的保護手段を回避していません

当サービスが参照するのは、Bluesky が認証なしで一般公開している API およびコンテンツ配信ネットワークです。DRM、署名付き URL、ログインゲートなどの技術的保護手段を回避する処理は一切行っていません。また、非公開設定の投稿、フォロワー限定の投稿、削除済みの投稿は取り扱いません。

3. 利用者の責任

当サービスを通じて保存されたコンテンツの利用は、著作権法が定める私的使用の範囲内に限られます。再配布、商業利用、無断転載は禁止しており、それらの行為に関する責任はすべて利用者に帰属します。

4. 権利侵害の申し立て（削除・掲載停止のご依頼）

権利者ご本人または正当な代理人の方から、権利を侵害する利用が行われている旨のご連絡をいただいた場合、当サイトは速やかに調査し、必要な対応（該当コンテンツの取り扱い停止、特定の投稿・アカウントの除外設定、ランキングページからの掲載除外など）を行います。

ご連絡の際は、お問い合わせページより、次の情報をお知らせください。

  • 権利を侵害されているとお考えの著作物の特定に足る情報

  • ご連絡先（返信可能なメールアドレス）
  • 申立人が権利者ご本人、または権利者を代理する権限を有する旨の表明

なお、当サイトはコンテンツをホスティングしていないため、Bluesky 上の投稿そのものの削除を行う権限はありません。投稿自体の削除をご希望の場合は、Bluesky（Bluesky Social, PBC）へ直接お申し出ください。

当サイトの人気動画ランキングは、公開投稿の再投稿数といいね数を集計し、Bluesky が配信するサムネイル画像と元投稿へのリンクを表示するものです。動画ファイルの複製・再配布は行っていません。掲載を希望されない場合は、上記のお問い合わせ先までご連絡いただければ、当該投稿または当該アカウントを集計対象から除外いたします。
