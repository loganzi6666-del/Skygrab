Blueskyの動画を保存する方法【2026年完全ガイド】

2026年09月24日 公開　／　文：Fujii Hina

Bluesky に投稿された動画を、あとから見返したい。手元に残しておきたい。そう思っても、Bluesky の公式アプリには「保存」のボタンがありません。

この記事では、ログインもアプリのインストールもせずに、iPhone・Android・パソコンのそれぞれで Bluesky の動画を端末に保存する手順を、つまずきやすい点まで含めて解説します。所要時間は1分ほどです。

保存する前に確認すること

手順に入る前に、2点だけ確認させてください。ここを外すと、そもそも保存できなかったり、あとでトラブルになったりします。

公開されている投稿だけが対象です

保存できるのは、ログインしていない状態でも誰でも見られる公開投稿だけです。ログインが必要な投稿、削除された投稿、投稿者が「ログアウト状態のユーザーに表示しない」設定にしているアカウントの投稿は取得できません。これは仕様上の制限であり、回避する方法はありません。

保存した動画は私的使用の範囲で

日本の著作権法では、私的使用を目的とした複製は認められています。一方で、保存した動画を再配布したり、SNS に無断で転載したり、商用利用したりすることは認められていません。また、違法にアップロードされたものだと知りながらダウンロードする行為も対象外です。

自分であとから見返す、資料として手元に置いておく。その範囲で使ってください。詳しくは利用規約と著作権・DMCA ポリシーに記載しています。

保存の手順（全デバイス共通）

使う端末にかかわらず、流れは同じ3ステップです。

ステップ1：投稿の URL をコピーする

Bluesky で保存したい動画の投稿を開き、投稿の下にある共有アイコンから「Copy link to post」（リンクをコピー）を選びます。パソコンのブラウザで見ている場合は、アドレスバーの URL をそのままコピーしても構いません。

コピーできる URL は次の形です。

https://bsky.app/profile/ユーザー名/post/投稿ID

ステップ2：URL を貼り付けて検索する

トップページの入力欄に、コピーした URL を貼り付けて「動画をダウンロード」ボタンを押します。アカウント登録もログインも必要ありません。

動画が見つかると、サムネイルと一緒に「動画の準備ができました」と表示されます。

ステップ3：ダウンロードする

もう一度ボタンを押すと、動画ファイルのダウンロードが始まります。

ここで1つだけ知っておいてほしいことがあります。当サイトは、投稿者がアップロードした動画ファイルそのものを Bluesky のサーバーから取り寄せてお渡ししています。作り直しや変換は行っていません。

そのため、ファイルを取り寄せるあいだ数秒から十数秒かかります。実測では3MB ほどの動画で約10秒でした。ボタンを押しても画面が動かないように見えることがありますが、故障ではありません。そのまま待ってください。

受け取れるファイルは bluesky-video-投稿ID.mp4 という名前の MP4 ファイルです。特別なアプリがなくても、標準の動画プレイヤーでそのまま再生できます。

iPhone・iPad で保存する

日本では iPhone を使っている方が多いので、ここは少し詳しく説明します。iPhone の場合、ダウンロードした動画はいったん「ファイル」アプリに入り、そのあと自分で「写真」アプリに移すという二段構えになります。ここを知らないと「保存したのに写真アプリに見当たらない」と混乱しがちです。

  1. Safari で上記のステップ1〜3を行います。
  2. ダウンロードの確認が出たら「ダウンロード」を選びます。
  3. アドレスバー付近に下向き矢印のアイコンが現れます。これをタップすると、ダウンロード済みのファイル一覧が開きます。
  4. ファイル名をタップすると「ファイル」アプリが開き、動画が再生できます。
  5. 写真アプリに入れたい場合は、動画を再生している画面で共有ボタンを押し、「ビデオを保存」を選びます。これでカメラロールに入ります。

「ファイル」アプリのままで良ければ、5番目の操作は不要です。なお、表示や名称は iOS のバージョンによって多少異なります。

Android で保存する

Android は iPhone よりも単純です。

  1. Chrome などのブラウザで、ステップ1〜3を行います。
  2. ダウンロードが始まると、画面下部または通知領域に進捗が表示されます。
  3. 完了したら通知をタップすると、動画がそのまま再生されます。
  4. ファイルは端末の「Download」フォルダに入ります。「Files」アプリや「ギャラリー」アプリから確認できます。

機種によっては、ギャラリーアプリに反映されるまで少し時間がかかることがあります。すぐ見当たらない場合は、ファイル管理アプリで Download フォルダを直接開いてみてください。

パソコン（Windows・Mac）で保存する

パソコンがいちばん手間がかかりません。

  1. ブラウザで Bluesky を開き、投稿の URL をアドレスバーからコピーします。
  2. 当サイトの入力欄に貼り付けて実行します。
  3. ダウンロードボタンを押すと、ブラウザの既定のダウンロードフォルダに MP4 ファイルが保存されます。

Windows なら「ダウンロード」フォルダ、Mac なら「ダウンロード」フォルダが既定の保存先です。保存先を変えたい場合は、ブラウザの設定で「ダウンロード前に各ファイルの保存場所を確認する」を有効にしておくと、毎回選べるようになります。

保存できないときは

うまくいかない場合、原因はだいたい次のどれかです。

  • 「投稿が見つかりません」　投稿者が「ログアウト状態では非表示」に設定しているか、投稿が削除されています。
  • 「動画がありません」　画像だけの投稿か、引用投稿です。引用の場合は引用元のURLを使ってください。
  • 反応がないように見える　処理中です。数秒から十数秒かかります。
  • 保存したのに見つからない　iPhoneでは「ファイル」アプリに入ります。

症状ごとの詳しい原因と対処法は、Blueskyの動画が保存できない原因と対処法7選でまとめています。

よくある質問

無料ですか？

はい。無料で、回数の制限もありません。アカウント登録も不要です。

ログインは必要ですか？

必要ありません。Bluesky のアカウントを持っていなくても使えます。当サイトがパスワードを尋ねることは一切ありません。

保存した動画はサーバーに残りますか？

残りません。当サイトは動画ファイルを保存していません。詳しくはプライバシーポリシーをご覧ください。

相手に通知されますか？

されません。Bluesky には、動画を保存したことを投稿者に知らせる仕組みはありません。

画質は落ちますか？

投稿者が Bluesky にアップロードしたファイルそのものを保存します。当サイトで再エンコード（作り直し）は行っていません。ただし、Bluesky にアップロードされた時点で圧縮がかかっているため、撮影時の元データと同じにはなりません。

音が出ません

元の投稿に音声が含まれていない可能性があります。Bluesky で再生したときに音が出ているかを先に確認してください。

まとめ

Bluesky の動画保存は、URL をコピーして貼り付けるだけです。つまずきやすいのは次の2点だけでした。

  • ファイルを取り寄せるのに数秒から十数秒かかる（待てば始まります）
  • iPhone ではいったん「ファイル」アプリに入る（写真アプリに移すには一手間必要）

この2つさえ知っていれば、あとは迷うところはありません。

いま Bluesky で多く共有されている動画は、人気動画ランキングからも探せます。気になったものはその場で保存できます。
