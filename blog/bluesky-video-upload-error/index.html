Blueskyに動画が投稿できない原因と解決方法

2026年9月24日 公開　／　文：Fujii Hina

Blueskyに動画を投稿しようとしたら、エラーが出た。アップロードが途中で止まる。そもそも動画が選べない。

原因はほぼ4つに絞れます。しかもいちばん多いのは「上限を勘違いしている」ケースです。ここが厄介で、ネット上に出回っている数字の多くがすでに古くなっています。まずそこから整理します。

現在の上限（2026年9月時点）

まず結論です。Blueskyの公式アプリが受け付ける動画の条件は次のとおりです。

長さ最大10分
ファイルサイズ最大300MB
対応形式MP4 / MPEG / WebM / MOV（QuickTime）/ GIF
1投稿あたり動画は1本まで
字幕ファイル20個まで

この数字は、Blueskyの公式アプリのソースコードおよびAT Protocolの仕様定義で確認したものです。ご自身の投稿がこの範囲に収まっているか、まず確かめてください。

「60秒まで」は古い情報です

ここが重要です。「Bluesky 動画 投稿できない」で検索すると、「動画は60秒まで」と書かれた記事が今でもたくさん出てきます。これは2024年9月に動画機能が始まったときの数字で、すでに引き上げられています。

容量についても同じです。当初は100MBでしたが、現在は300MBまで拡張されています。仕様定義にも「以前は100MBに制限されていた」と明記されています。

つまり「1分を超えているから投稿できないんだ」と諦めていた方は、もう一度試してみる価値があります。10分以内なら通るはずです。

逆に言えば、古い記事を読んで「60秒に収めたのにエラーが出る」という場合、原因は長さではなく別のところにあります。以下を順番に確認してください。

原因1：ファイル形式が対応していない

意外と多いのがこれです。対応しているのは MP4 / MPEG / WebM / MOV / GIF で、それ以外は選択しても弾かれます。

とくに次のような場合に引っかかります。

  • AVI、WMV、FLV、MKVなどの形式　古い動画ファイルや、録画ソフトの初期設定でよくある形式です。
  • 音声コーデックが特殊な場合　拡張子がMP4でも、中身のコーデックによっては処理に失敗することがあります。

対処法はシンプルで、MP4（H.264）に変換してから投稿することです。スマートフォンで撮影した動画はたいていこの形式なので、問題になるのはパソコンで編集・書き出した動画がほとんどです。編集ソフトの書き出し設定で「MP4」「H.264」を選んでください。

原因2：長さ・容量が上限を超えている

10分・300MBを超えていないか確認してください。とくに容量のほうが先に上限に当たりやすいです。高画質で撮影した動画は、数分でも300MBを超えます。

4K撮影やiPhoneの高フレームレート設定だと、1分で数百MBに達することもあります。長さが10分以内でも容量で弾かれるわけです。

対処法は次のいずれかです。

  • 解像度を下げて書き出す　1080p（フルHD）に落とすだけで容量は大きく減ります。スマホで見る分には画質の差はほとんど分かりません。
  • 動画を分割する　1投稿に動画は1本までなので、長い動画は分けてスレッドとして連続投稿する形になります。
  • 不要な部分をカットする　前後の余白を削るだけでも効果があります。

原因3：1日の投稿上限に達している

Blueskyには1日あたりの動画投稿数の上限があります。公式が動画機能を発表した際には1日25本／合計10GBまでと案内されていました。

ただしこの数字は発表当時のもので、公式も「調整する可能性がある」と述べています。現在の正確な値は公表されていないため、参考値として扱ってください。

連続して何本も投稿したあとにエラーが出る場合は、これに当たっている可能性があります。対処法は時間を置くことだけです。日付が変わればリセットされます。

原因4：通信・アプリ側の問題

上記のどれにも当てはまらない場合、環境側の問題を疑います。

  • 通信が不安定　動画のアップロードは画像よりはるかに時間がかかります。電波の弱い場所やテザリング中は失敗しやすくなります。Wi-Fiの安定した場所で試してください。
  • アプリのバージョンが古い　上限の引き上げなどはアプリ側の更新で反映されます。App Store / Google Play で更新を確認してください。
  • ストレージの空き不足　端末側で一時ファイルを作るため、空き容量が少ないと失敗します。
  • アプリの一時的な不具合　アプリを完全に終了して再起動すると直ることがあります。

それでも投稿できないとき

ここまで試して解決しない場合は、次の順で切り分けます。

  1. 別の短い動画で試す　10秒程度のスマホ撮影動画を投稿してみます。これが通るなら、元の動画のファイル側に原因があります。
  2. ブラウザ版で試す　パソコンのブラウザから bsky.app にアクセスして投稿してみます。アプリ固有の問題かどうかが分かります。
  3. 時間を置く　Bluesky側で一時的な障害が起きていることもあります。数時間後に再度試してください。

よくある質問

動画は何分まで投稿できますか？

最大10分です。サービス開始当初は60秒でしたが、現在は引き上げられています。

ファイルサイズの上限は？

300MBです。こちらも当初の100MBから拡張されています。

1つの投稿に動画を2本入れられますか？

できません。1投稿につき動画は1本までです。複数本を見せたい場合は、スレッドとして連続投稿してください。

GIFは投稿できますか？

できます。対応形式に含まれています。

投稿した動画をあとから差し替えられますか？

できません。投稿を削除して、投稿し直すことになります。

まとめ

「投稿できない」の原因は、順に確認すればほぼ特定できます。

  1. 形式はMP4 / MPEG / WebM / MOV / GIFか
  2. 10分・300MB以内か
  3. その日に何本も投稿していないか
  4. 通信とアプリの更新は問題ないか

そして繰り返しになりますが、「60秒まで」という情報を見て諦めた方は、もう一度試してください。今は10分まで通ります。
