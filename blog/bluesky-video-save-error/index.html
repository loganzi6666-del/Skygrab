Blueskyの動画が保存できない原因と対処法7選

2026年9月24日 公開　／　文：Fujii Hina

URLを貼ったのに動画が出てこない。ボタンを押しても何も起きない。保存したはずなのに見当たらない。

症状ごとに原因は違います。この記事では症状から原因を逆引きできるように7つのケースを整理しました。上から順に確認すれば、ほぼ特定できます。

目次

  1. 1. 投稿者が「ログアウト状態では非表示」に設定している
  2. 2. 投稿が削除されている／非公開になっている
  3. 3. その投稿に動画が入っていない
  4. 4. URLが途中で切れている
  5. 5. まだ処理中（待てば始まります）
  6. 6. 保存できているのに見つけられない（iPhone）
  7. 7. ブラウザ・通信側の問題
  8. よくある質問

1. 投稿者が「ログアウト状態では非表示」に設定している

症状：「投稿が見つかりません」と出る。でもBlueskyのアプリでは普通に見られる。

これがいちばん多く、いちばん分かりにくい原因です。Blueskyには、自分の投稿をログインしていない人に見せない設定があります。この設定をオンにしているアカウントの投稿は、ログインしていない外部のツールからは一切取得できません。

日本のユーザーはこの設定を使っている方が比較的多く、とくに創作系・イラスト系のアカウントでよく見かけます。

対処法：残念ながらありません。これは投稿者本人が「ログインしていない人には見せない」と明示的に選んだ設定です。当サイトはその意思を尊重して取得を行いません。どうしても必要な場合は、投稿者ご本人に直接お願いしてください。

2. 投稿が削除されている／非公開になっている

症状：「投稿が見つかりません」と出る。Blueskyで開いても表示されない。

投稿そのものが消えています。投稿者が削除した、アカウントを削除した、あるいはアカウントが一時的に停止されている、のいずれかです。

対処法：元の投稿が存在しない以上、取得できません。別の投稿URLで試してください。

3. その投稿に動画が入っていない

症状：「この投稿にはダウンロードできる動画がありません」と出る。

次のような投稿は、見た目が動画っぽくても対象外です。

  • 画像だけの投稿　当サイトの動画保存機能は動画専用です。
  • 外部サイトのリンクを貼っただけの投稿　YouTubeなどのリンクが貼られている場合、動画はBlueskyではなくその外部サイトにあります。
  • 引用投稿　これが見落としがちです。誰かの動画投稿を引用した投稿のURLをコピーすると、引用した側には動画の実体がありません。引用元の投稿を開いて、そちらのURLをコピーしてください。

4. URLが途中で切れている

症状：「Blueskyの投稿URLを入力してください」と出て、そもそも検索が始まらない。

正しい形は次のとおりです。

https://bsky.app/profile/ユーザー名/post/投稿ID

末尾の投稿IDまで含まれている必要があります。手動で選択してコピーすると、末尾が欠けたり、余計な文字が混ざったりしがちです。

対処法：手で選ばず、投稿の共有アイコンからリンクをコピーする機能を使ってください。確実です。パソコンならアドレスバーからのコピーでも構いません。

5. まだ処理中（待てば始まります）

症状：ボタンを押したのに、画面が固まったように見える。

当サイトは、投稿者がアップロードした動画ファイルそのものをBlueskyのサーバーから取り寄せてお渡ししています。作り直しや変換は行いません。そのためファイルを取り寄せる時間がそのままかかります。

実測では3MBほどの動画で約10秒でした。容量が大きい動画ほど長くなります。

対処法：待ってください。故障ではありません。1分以上たっても始まらない場合のみ、ページを再読み込みしてやり直してください。

6. 保存できているのに見つけられない（iPhone）

症状：ダウンロードは終わったのに、写真アプリを見ても動画がない。

保存は成功しています。iPhoneでは、ダウンロードしたファイルは「写真」アプリではなく「ファイル」アプリに入ります。これを知らないと「保存できていない」と誤解しがちです。

対処法：

  1. Safariのアドレスバー付近にある下向き矢印のアイコンをタップします。
  2. ダウンロード済みファイルの一覧が開くので、動画をタップします。
  3. 「ファイル」アプリで再生されます。ここで共有ボタンを押し、「ビデオを保存」を選びます。
  4. 写真アプリのカメラロールに入ります。

「ファイル」アプリに置いたままでよければ、3番以降は不要です。

7. ブラウザ・通信側の問題

症状：特定の端末やブラウザでだけうまくいかない。

  • プライベートブラウズ　ブラウザによってはダウンロードが制限されます。通常のウィンドウで試してください。
  • 広告ブロッカー・拡張機能　まれにダウンロードの処理を妨げます。一時的に無効にして試してください。
  • 端末の空き容量不足　保存先に空きがないと失敗します。
  • 通信が不安定　途中で切れると失敗します。安定したWi-Fiで試してください。

切り分けとしては、別のブラウザか別の端末で同じURLを試すのがいちばん早いです。それで成功するなら、元の環境側の問題だと分かります。

よくある質問

特定のアカウントの動画だけ保存できません

そのアカウントが「ログアウト状態のユーザーに表示しない」設定にしている可能性が高いです。上の 1番 をご覧ください。設定は投稿者本人しか変更できません。

Blueskyのアプリでは見られるのに保存できないのはなぜ？

アプリではあなたがログインしているため表示されますが、当サイトはログインせずに取得します。そのため、ログアウト状態で見られない投稿は取得できません。

引用投稿の動画を保存するには？

引用元の投稿を開き、そちらのURLをコピーしてください。引用した側の投稿には動画の実体が含まれていません。

何度やっても途中で止まります

容量の大きい動画ほど時間がかかります。安定したWi-Fi環境で、通常のブラウザウィンドウから試してみてください。

まとめ

症状別にまとめると次のとおりです。

  • 「投稿が見つかりません」　→ 非表示設定（1番）か削除済み（2番）。ほとんどが1番です。
  • 「動画がありません」　→ 画像投稿か引用投稿（3番）。
  • 検索が始まらない　→ URLが不完全（4番）。
  • 反応がないように見える　→ 処理中（5番）。待てば始まります。
  • 保存したのに見つからない　→ iPhoneの保存先（6番）。

基本的な手順そのものは、Blueskyの動画を保存する方法で解説しています。
